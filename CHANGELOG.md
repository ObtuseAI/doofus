## [1.1.0] - 2026-07-26

### Added

- First public research release of the nested evolution, MAP-Elites, metacognition,
  held-out benchmark, external-project, and live evidence surfaces.
- A visual project guide with system and promotion diagrams.
- Public security, contribution, citation, and release-readiness contracts.
- Explicit credential-discovery disablement for isolated public demos.

### Changed

- Renamed public-facing dashboard language around evidence-gated optimization.
- Replaced secret-shaped test fixtures with unmistakably generated test values.
- Sanitized workstation-specific paths while preserving local-first configuration.

## Scope

This release is experimental. Checked benchmark results are evidence about the named
tasks and seeds, not proof of general or real-world performance.
