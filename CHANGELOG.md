## [1.2.0] - 2026-07-30

### Added

- Agora, an attended six-node invention and debate swarm with four measured
  reserve providers, frozen mission contracts, blind critique, correlation
  grouping, minority preservation, and information-gain stopping.
- An isolated hash-chained SQLite event ledger and SHA-256 content-addressed
  vault for prompts, responses, evidence captures, reports, and receipts.
- A keyless evidence fabric with bounded public retrieval, SSRF defenses,
  explicit source failures, claim adjudication, and recorded novelty searches.
- Exact CandidateSpecs and a disposable WSL2 `bubblewrap` laboratory requiring
  independent implementations, independently authored tests, and bounded
  differential execution.
- Evidence-based decision analysis, outcome attribution, a dedicated
  quality-diversity archive, Problem Foundry, and proposal-only
  problem-solution tournaments.
- The `doofus-agora` command line and scoped Agora dashboard for attended
  mission operation, evidence inspection, candidate comparison, experiment
  receipts, and attribution history.

### Changed

- Advanced the package and citation metadata to v1.2.0.
- Reframed the public landing page around the unified invention, evidence,
  experiment, evolution, and operator-authority journey.
- Extended public-release readiness to inspect both tracked and untracked
  review-state source files.

### Security

- Consumer-provider browser automation remains disabled. `ASSISTED` operation
  is limited to local clipboard and file staging.
- Missing context classification fails closed as `SECRET`; secret context is
  never exportable.
- Provider responses remain inert and untrusted, external dependencies remain
  blocked until verified and approved, and successful candidates cannot modify
  the primary repository.

## [1.1.0] - 2026-07-26

### Added

- First public research release of the nested evolution, MAP-Elites, metacognition,
  held-out benchmark, external-project, and live evidence surfaces.
- A visual project guide with system and promotion diagrams.
- Public security, contribution, citation, and release-readiness contracts.
- Explicit credential-discovery disablement for isolated public demos.

### Changed

- Renamed public-facing dashboard language around evidence-gated optimization.
- Replaced secret-shaped test fixtures with unmistakably generated test values.
- Sanitized workstation-specific paths while preserving local-first configuration.

## Scope

This release is experimental. Checked benchmark results are evidence about the named
tasks and seeds, not proof of general or real-world performance.
